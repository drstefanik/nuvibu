# Identità visiva Nuvibù

Questa cartella contiene la direzione visiva corrente del canale.

## Asset principali

- `nuvibu-avatar-800.png`: avatar canale 800×800;
- `nuvibu-youtube-banner-2560x1440.png`: banner con elementi essenziali dentro la safe area centrale;
- `source/nuvibu-key-art.png`: key art ad alta risoluzione da usare come riferimento del personaggio;
- `concepts/cucu-dietro-la-nuvola.png`: concept thumbnail episodio;
- `concepts/pulcini-arcobaleno.png`: concept thumbnail episodio;
- `concepts/nuvibu-soft-concept.png`: precedente esplorazione morbida, conservata solo come riferimento.

La mascotte approvata non è un semplice smiley: è un personaggio 3D ricorrente con silhouette, occhi, ciuffo, arti, piedi ed emblema arcobaleno bloccati nella Character Bible (`data/character_bible_template.json`).

Prima della produzione seriale vanno creati turn-around, expression sheet, pose sheet e reference 16:9 coerenti. Le immagini concept non sostituiscono un rig 3D o un sistema di character consistency.
